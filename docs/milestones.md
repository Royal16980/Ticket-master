# Engineering Milestones

## Phase 1: Platform setup + auth + event management
- Deliver monorepo scaffold, role model, event CRUD baseline.
- Done when signup + organiser event creation are functional.

## Phase 2: Payments, orders, QR tickets
- Deliver checkout workflow, order records, QR issuance, inventory controls.
- Done when checkout returns paid order with unique QR tickets.

## Phase 3: Rewards, referrals, profiles
- Deliver point ledger, share links, friend purchase reward attribution.
- Done when points are granted for share + purchase + referral conversion.

## Phase 4: Admin moderation and control
- Deliver admin overview, fraud flag placeholders, analytics stream.
- Done when platform-level metrics can be queried from one endpoint.

## Phase 5: Promotion + advanced analytics
- Segment campaigns, recommendation engine, external analytics sinks.
- Done when event and conversion telemetry is exported with stable schema.
